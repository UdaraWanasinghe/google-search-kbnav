# Google Search Keyboard Navigator

Navigate Google search results quickly without reaching for your mouse.

Google Search Keyboard Navigator adds simple, familiar keyboard shortcuts to
Google Search. Move between results, open the selected page, jump directly to a
numbered result, or return to the search box—all from the keyboard.

## Features

- Navigate forward and backward through search results.
- Open the selected result in the current tab or a new tab.
- Jump directly to results 1–9.
- Focus the Google search box instantly.
- Display an on-page shortcut reference when needed.
- Automatically ignore shortcuts while you are typing in a form field.
- Support Google Search across multiple regional Google domains.

## Keyboard shortcuts

- `j`, `s`, or `↓`: Select the next result.
- `k`, `a`, or `↑`: Select the previous result.
- `Enter`: Open the selected result.
- `o`: Open the selected result in a new tab.
- `1`–`9`: Jump to the corresponding result.
- `/`: Focus and select the search box.
- `Esc`: Clear the current selection or leave a focused form field.
- `?`: Show or hide the shortcut help panel.

## Privacy

Google Search Keyboard Navigator runs only on supported Google Search result
pages. It does not collect, store, or transmit personal information, browsing
history, search queries, or analytics. No account or additional configuration
is required.

## Getting started

Install the extension, open a supported Google Search page, and press `j` or
`↓` to select the first result. The selected result is highlighted so you can
see exactly what will open when you press `Enter`.
